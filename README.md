# SmartRetail_EDA_Auditoria_Do-aEva
Análisis exploratorio de datos de ventas - Proyecto de portafolio
Este proyecto consiste en un Análisis Exploratorio de Datos (EDA) enfocado en la auditoría de ventas de un entorno minorista. El objetivo es identificar patrones de consumo, métricas clave de desempeño y áreas de oportunidad para la optimización de procesos comerciales.

📊 Descripción del Proyecto
El análisis se basa en un conjunto de datos que abarca 79,131 transacciones, procesadas para evaluar el comportamiento del cliente y la eficiencia operativa.

Hallazgos Principales
Integridad de Datos: Se alcanzó una integridad del 100% (sin registros nulos).

Ticket Promedio: El valor promedio por transacción es de 10.42 Bs.

Comportamiento de Compra: La mediana de artículos por compra es de 1.0 unidad, reflejando un modelo de alta rotación.

Estrategia: El negocio se caracteriza por un margen neto promedio de 1.71 Bs por transacción.

🛠️ Tecnologías Utilizadas
Lenguaje: Python

Librerías: pandas para manipulación de datos, matplotlib/seaborn para visualización.

Entorno: Google Colab.
